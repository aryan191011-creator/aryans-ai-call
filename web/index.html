Mic blocked. A browser only hands over a microphone on https:// or localhost, and an embedded preview needs the parent frame to allow it. Open in a new tab → The call still works without a mic: type, and it answers out loud.

Speak while it talks and it stops. Small backchannels — haan, okay, mhm — only duck the volume; a real interrupt like ruko or wait cuts it. Esc always cuts.

Setup

₹0 — free tiers only. One Google key, no card. It is the only secret in this app, which is why there is a mode where the browser never holds it.

Gemini API key Free, no card: aistudio.google.com/apikey

Key lives in localStorage on this device and goes straight to Google. Server-side instead: PROXY=1 GEMINI_API_KEY=… npm i ws && npm start.

One row hears you, decides, and speaks — the call and the voice preview use this same row. Pick it here, not in code.

Test connection asks your key which Live rows exist and retries once per change, so a retired name is never blamed on you.

The voice name goes into the Live setup frame, where the row actually reads it. Adjectives are not enough — hear it on the next tab.

A throwaway Live session — no microphone, no persona, nothing saved. It costs one request and speaks through the same chain as a call, so this is the sound you will actually hear.

No style directive is sent with the line: a Live session reads instructions as content, so "say this warmly" comes back as the model saying the words. Style belongs in the persona.

When a sentence ends is the whole difference between a conversation and a walkie-talkie. Three knobs, and they pull against each other.

The guard disables barge-in on purpose: on speakers the agent hears itself and interrupts itself into nonsense. Headphones users want it off, and that is a decision, not a default to discover.

The setup frame is a proto: a field the row does not know is not ignored, it is a rejected setup — which arrives as a dead socket that looks exactly like a bad key. So the newer fields are asked for only where they are documented.

Accessibility

Averages hide the calls people remember, so the strip under the thread shows p50 and p95, not a mean. It counts this page load only.

  • turn — silence to first agent audio. What the caller feels. Over ~1200 ms reads as a bad line.
  • spread — p50/p95 of the same number. Averages hide the two calls out of twenty that were awful.
  • audio — how much the agent actually played.
  • calls — sessions started. The free tier counts requests per day.
  • tok — Live tokens so far: the closest thing to a bill on a ₹0 stack.

Measured before and after a change is the only way to know a setting helped. Reset here, change one thing on another tab, then compare.

What this is, said plainly: a browser tab that talks to Google. It is not a phone number, and no ₹0 stack is.

  • A friend "calls" it when you send the link and they tap the mic — that needs https://, because getUserMedia does.
  • Dialling a real number costs money per minute at every provider, and India adds TRAI/DLT rules for commercial outbound.
  • A real landline answer is possible for ₹0 over Bluetooth HFP with your own Android as the modem — Linux, oFono, no cloud. That is a build, not a setting.
  • Jio Fiber can forward an inbound call to your mobile for free, and the AI can answer it there.

If the mic never arrives, the page tells you why under the composer rather than pretending to listen.
